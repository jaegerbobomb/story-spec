## Goal

A visitor can create an account and sign in, so that everything else in the
application can be tied to a person.

## Exit criteria

- [x] A visitor can register with an email and a password
- [ ] A registered user can sign in and sign out
- [ ] A user who forgot their password can reset it without contacting support

## Out of scope

Single sign-on and social logins.
